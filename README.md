## 👨‍💻 About me

- 💼 **Front-End Developer at Cord Digital** (2024 – present), building websites, e-commerce stores and dashboards for clients in Egypt and Saudi Arabia.
- 🧑‍🔧 **Freelancing since 2022**: production sites for real businesses, from the first requirement to launch and support.
- 🔍 **SEO is part of every build**: metadata and canonicals, `hreflang`, JSON-LD structured data, sitemaps, Open Graph images and Core Web Vitals.
- 🧪 **I test what I ship.** Manual QA before every release, and Playwright end-to-end suites running in GitHub Actions on my projects (cart → checkout flows, filters, RTL, SEO checks, accessibility scans).
- 🌍 **Bilingual by default**: Arabic RTL and English LTR, server-rendered with the right `lang` / `dir`.
- 🔌 **Back-end aware**: I integrate REST APIs and work with Laravel / PHP back ends and Supabase (PostgreSQL).

## ✅ How I ship

```text
Requirements ─▶ Responsive, RTL-ready UI ─▶ API integration ─▶ SEO setup ─▶ Manual QA + E2E tests in CI ─▶ Deploy ─▶ Support
```

- **SEO checklist:** unique titles and descriptions, canonical + `hreflang`, Open Graph images, JSON-LD, `sitemap.xml`, `robots.txt`
- **QA checklist:** functional, regression, cross-browser and device testing, plus Playwright flows that run on every push
- **Performance:** optimized images and fonts, lazy loading, code splitting, Core Web Vitals checked with Lighthouse
